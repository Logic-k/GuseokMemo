# Peekom(빼꼼 인덱스) 기능 분석

분석일: 2026-11-14
대상: https://www.peekom.com/ 및 공개 소개·도움말·FAQ·기능 비교·변경 이력·설정 화면 자료
방법: 공개 자료 기반 기능 인벤토리 + 동작 관찰 (유료 바이너리 리버싱·코드 복제 없음)

---

## 1. 제품 정체

- Windows용 **화면 가장자리 인덱스 메모** 앱.
- 화면 오른쪽/왼쪽 가장자리에 세로 탭(인덱스)이 항상 떠 있고, 클릭하면 메모 패널이 열림.
- Electron 기반(약 100MB+)으로 알려져 있으며, 무료 3개 인덱스 / 유료(Plus) 10개 모델.

## 2. 기능 인벤토리

### 2.1 인덱스 손잡이
| 항목 | 내용 | 무료/Plus |
|---|---|---|
| 가장자리 표시 | 화면 좌/우 가장자리, 세로 탭 | 무료 |
| 인덱스 개수 | 3개 / 10개 | 무료 / Plus |
| 제목 | 탭에 세로로 표시, 짧은 글자 수 제한(8~16자) | 무료 |
| 색상 | 인덱스별 배경/글자 색 | 일부 Plus |
| 위치 이동 | 드래그로 위아래 이동, 슬롯별 위치 저장 | 기본 / Plus(슬롯별) |
| 열기/닫기 | 탭 클릭 | 무료 |

### 2.2 표시 모드
| 모드 | 동작 |
|---|---|
| 빼꼼(PEEK) | 마우스가 떠나면 자동으로 접힘 |
| 얼음(ICE) | 화면에 고정, 자동으로 접히지 않음 |

- 패널 하단 칩으로 전환.

### 2.3 메모 편집
- 굵게, 기울임, 밑줄, 취소선
- 정렬(좌/중앙/우)
- 글머리 기호, 번호 목록
- 체크리스트: 완료 시 취소선, 상태 저장
- 이미지: 첨부, 비율(1:1/4:3/3:4/16:9), 크기 조절, 삭제 — Plus 성격
- 자동 마크다운: `#`, `##`, `###`, `-`, `1.`, `- [ ]`, `**`, `*`, `~~`
- 맞춤법 검사 on/off
- 글자 크기 10~40, 글꼴 선택
- 메모 비율 1:1, 4:3, 3:2, 16:9, 3:4, 2:3
- 배경 불투명도 25~100%

### 2.4 색/디자인
- 테마 프리셋(크림/핑크/블루/그린/라벤더 계열)
- 배경/글자 직접 지정
- 강조 색

### 2.5 창/모니터
- 표시 모니터: 자동(마우스 위치) 또는 고정
- 표시 위치: 오른쪽/왼쪽
- 자동 접힘 지연 시간

### 2.6 단축키
- 열기/닫기 전역 단축키(기본 Ctrl+Shift+M 계열)
- 이전/다음 인덱스
- 숫자 키로 인덱스 바로 열기
- Ctrl+휠 글자 크기, Esc 닫기, Ctrl+S 저장

### 2.7 시스템 통합
- 트레이 아이콘 + 메뉴(설정/열기·닫기/종료)
- Windows 시작 시 자동 실행
- 다중 모니터 대응

### 2.8 데이터
- 로컬 저장(클라우드 없음)
- JSON 백업/복원
- TXT/MD 내보내기
- 저장 상태 표시

## 3. 무료 vs Plus (관찰된 구분)

| 기능 | 무료 | Plus |
|---|---|---|
| 인덱스 수 | 3 | 10 |
| 인덱스별 세부 설정 | 제한적 | 대부분 |
| 슬롯별 손잡이 위치 | - | O |
| 이미지 첨부 | - | O |
| 일부 테마/투명도/비율 | - | O |

> 정확한 가격·정책은 Peekom 공식 페이지가 우선이며, 본 문서는 기능 범위 파악용입니다.

## 4. 재구현 시 결정

- **모든 기능을 무료로 개방** (라이선스/계정 없음).
- 인덱스 10개, 테마 5종 + 직접 색상, 이미지 5장, 비율 6종.
- 슬롯별 위치 대신 **공통 세로 위치 1개** + 스냅 (단순화, 문서화).
- 클라우드/모바일/팀 공유는 범위에서 제외 (Peekom도 미제공).
- 원본 코드·이미지·아이콘·브랜드 자산을 사용하지 않고, 기능만 클린룸 재구현.
