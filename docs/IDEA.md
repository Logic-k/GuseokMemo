# IDEA — 구석메모 다음 개발 방향

## 문제·사용자·가치

- **문제**: 구석메모는 무료 Peekom 재구현으로 이미 완성 단계(v0.2.4)에 도달.
  이제 "메모 10개짜리 도구"를 넘어 **사무실 개인 생산성 허브**로 쓸 만한 빈 기능이 남아 있다.
- **사용자**: Windows 사무실 사용자 1인(개발자 본인). 동시에 GitHub 무료 배포로
  "Peekom Plus 기능을 무료로 쓰고 싶은 소규모 사무실" 일반 사용자.
- **가치**: 인덱스 10개는 검색 없으면 오히려 약점. 리마인더는 무료 스티키 앱의 최다 불만.
  이 둘만 넣어도 "무료 Peekom 이상"이 된다. 동기화는 계정 없이 폴더 지정으로 로컬-퍼스트 유지.

## 첫 버전 범위

- **(미정)** 첫 버전에 포함할 항목 — 위 표에서 사용자가 고른다.
- **(미정)** 리마인더 알림 방식(토스트/패널 강조/소리).
- **(미정)** 폴더 동기 충돌 정책(최신 파일 승 vs 병합/보관).

## 운영·안전 조건

- 로컬-퍼스트 원칙 유지: 계정·서버·분석·광고 없음. 유일한 네트워크는 업데이트 확인.
- 자동시작/트레이 잔재 없음 (전역 규칙 — 테스트 후 정리).
- IME 품질 원칙: 조합 중 DOM/속성 변경 금지.
