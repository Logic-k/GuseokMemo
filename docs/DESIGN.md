# DESIGN — 신규 UI 미리보기

이 문서는 구현 전 승인용 미리보기다. 각 절은 **제안(기본안)** 과 **결정 대상**을 구분한다.
기존 화면 언어(반투명 카드, 12~13px 본문, 둥근 칩, blur 배경)를 그대로 계승한다.

승인 기록은 이 파일 맨 아래 "승인 로그"에 남긴다.

---

## D-1 전체 검색 UI (R-01) — phase-02-task-02

### 제안: 별도 `search` 창

- **형태**: settings와 동급의 독립 창(setup 생성·hide/show 재사용, NFR-06).
  검색은 "어느 인덱스를 열었든" 동일해야 하므로 패널 내 오버레이 대신 전역 창.
- **진입점**:
  1. 전역 단축키 `Ctrl+Shift+F` (register_shortcuts에 프리셋 추가)
  2. 패널 툴바의 돋보기 버튼(`btnSearch`, `btnImage` 왼쪽)
- **레이아웃** (세로 ~460px 폭 × 400px, always-on-top):
  - 상단 고정 검색 입력(placeholder `검색`, 자동 포커스)
  - 결과 리스트: 인덱스 색 칩(2px 라운드 바) + 제목 + 스니펫(매칭 어절 굵게)
  - 매칭 0건 → `결과 없음` 중앙 표시
  - ↑/↓ 키 이동 + Enter 점프, 클릭 점프, `Esc`/외부 클릭/점프 후 자동 닫힘
- **동작**: 입력마다 디바운스 120ms로 메모리 `state.indexes` 검색(숨긴 인덱스 제외).
  IME 조합 중에는 결과 DOM 갱신 유예(NFR-02 — 조합 파기 방지).
  결과 클릭 → `show_panel`(기존 open 경로)로 해당 인덱스 점프.
- 대안 기각: 패널 내 오버레이 — 인덱스마다 다른 폭/테마에 종속되고 창 수명이 복잡.

**결정 대상**: 별도 창(제안) vs 패널 내 오버레이 / 진입점 조합

## D-2 리마인더 설정·알림 (R-02/03) — phase-03-task-02

### 제안

- **설정 위치**: 패널 헤더의 시계 버튼(`btnRemind`, 설정 톱니 왼쪽) → 작은 팝오버
  (fontPop과 동일 스타일): 시간 입력(`datetime-local` 대신 간결한 `HH:MM` + 오늘/내일
  칩) + 반복 선택(없음/매일/매주) + `[설정]` `[해제]` 버튼.
  메모에 붙는 리마인더이므로 패널이 자연스러운 위치.
- **목록/해제**: 설정 창 `리마인더` 탭 신설 — 예약된 리마인더 목록(제목+시각+반복)과
  개별 해제/일괄 해제. 놓친 리마인더는 `놓침` 뱃지로 구분.
- **알림 전달**: 발화 `guseok://reminder` 수신 시 전 창이 받되 **handles 창이 대표 전달** —
  (a) 앱 내 토스트(스트립 옆에 4초 표시, 클릭 시 해당 메모 열기)
  (b) 해당 인덱스 핸들 강조(펄스 애니메이션, 클릭할 때까지)
  (c) 소리 — 선택 시 `tauri` 알림음 또는 가벼운 beep
- 패널이 닫혀 있어도 도달(토스트는 OS가 아닌 앱 내 창이라 권한 불필요).

**결정 대상**: 알림 방식 = **OQ-02**(토스트/핸들 강조/소리, 복수 가능) /
리마인더 설정 위치(패널 팝오버 제안 vs 설정 전용)

## D-3 저장 폴더 설정 UI (R-04/05) — phase-04-task-04

### 제안

- 설정 창 `저장` 탭 신설(기존 탭열 맨 뒤):
  - 현재 저장 폴더 경로 표시(길면 중간 생략, 클릭 시 폴더 열기)
  - `[폴더 변경…]` — tauri-plugin-dialog 폴더 선택 → `set_data_dir` 호출
  - `[기본값으로 되돌리기]` — %APPDATA% 경로로 복귀
  - 쓰기 불가/존재하지 않는 경로 선택 시 빨간 오류 문구 + 기존 경로 유지
  - 외부 변경 자동 리로드 상태 표시(`감시 중`/일시 중단 표시 + 마지막 리로드 시각)
- 충돌 정책 문구는 OQ-03 확정 후 같은 탭에 1줄 안내만 추가.

**결정 대상**: 탭 신설(제안) vs 기존 `앱` 탭 하단 섹션

## D-4 다크모드 (R-08) — phase-05-task-03

### 제안

- **적용 범위**: 설정 창 전체 + 패널 크롬(헤더·툴바·팝오버) + 스트립 `+` 버튼·토스트·
  검색 창 — **메모 카드 배경/글자색과 핸들 색은 인덱스 테마 유지(덮어쓰기 금지, R-08 계약)**
- **모드**: `라이트 / 다크 / 시스템 따르기` — 설정 `앱` 탭의 테마 행에서 선택
  (`common.darkMode`, system은 `matchMedia("(prefers-color-scheme: dark)")` + 변경 감지)
- **다크 팔레트 제안**:
  - 배경 `#17181f`, 카드 `#1f2029`, 텍스트 `#e8e6df`, 보조 텍스트 `#9a98a8`
  - 테두리 `rgba(255,255,255,.09)`, hover `rgba(255,255,255,.08)`
  - 액센트(체크·링크·활성)는 기존 계열 유지(`#4a6b8a` 계열 → 다크에서 채도 +8%)
- 구현: CSS 변수 토큰(`--chrome-bg` 등) 전환 — 라이트는 현재 값이 기본값.

**결정 대상**: 팔레트 수용 / 적용 범위(설정 창만 vs 전체 크롬)

## D-5 템플릿·스니펫·숨김 토글 UI (R-06/07) — phase-05-task-04

### 제안

- **템플릿 선택**: 스트립 `+` 클릭 → 40px 스트립 안이 아니라 **패널 위치에 작은 선택 창**
  (fontPop 스타일 팝업, 세로 목록: `빈 메모` + 사용자 템플릿들) → 선택 시 새 인덱스
  생성+열림. `Esc`로 취소.
- **스니펫 삽입**: 패널 툴바 `❖` 버튼 → 팝오버에 스니펫 목록 → 클릭 시 커서 위치에 삽입
  (치환자 `{{date}}` `{{time}}`는 코어가 이미 처리). 스니펫 편집은 설정 `템플릿` 탭.
- **템플릿/스니펫 편집**: 설정 `템플릿` 탭 신설 — 이름+내용 행 목록, 추가/삭제/미리보기.
- **인덱스 숨김 토글**: 설정 `메모` 목록 각 행에 눈 아이콘 버튼(기존 삭제 버튼 옆) —
  숨긴 인덱스는 반투명 + `숨김` 표시. 마지막 1개는 숨김 불가(코어 보호 로직 있음).
  스트립 우클릭 메뉴 확장은 보류(현재 우클릭=삭제 무장, 혼동 방지).

**결정 대상**: 템플릿 선택 위치(`+` 팝업 제안 vs 설정만) / 스니펫 진입점

## 공통 규칙

- 새 창은 모두 setup 생성 + hide/show(NFR-06, BUG-18 회귀 방지)
- 모든 입력창에서 IME 조합 중 DOM·스타일 미변경(NFR-02)
- 팝오버는 `fontPop` 스타일 계열 재사용 — 외부 클릭 닫힘
- 시각 보존 변경(버그 수정)은 이 문서 범위 밖, 별도 승인 불필요
