# 구석메모 다음 개발 방향 — 리서치 종합

입력: research/raw/q01.md(경쟁), q02.md(Tauri 함정), q03.md(기능 트렌드), q04.md(테스트 하네스)
검증: research/review/round-1.md

## 결정

**제품 방향**: 직접 경쟁(화면 가장자리 인덱스 메모)은 사실상 Peekom(유료)뿐이고,
GitHub 같은 컨셉 신생 프로젝트는 별 수 한두 자리 — 구석메모가 이미 선두권.
다음 개발은 **"무료 Peekom 이상"의 견고화 + 없는 기능의 신중한 추가**로 정한다.

**기능 우선순위 (두 조사의 일치 기준)**:

- **P0 — 전체 검색/관리 창**: 10개 인덱스 구조는 검색 없이 약점. Simple Sticky Notes·
  Notezilla 등 대중 앱 모두 보유. 트레이/단축키로 여는 검색+인덱스 점프.
- **P0 — 리마인더/알림**: 무료 스티키 앱 사용자의 최다 불만. 인덱스별 시각 알림
  (+반복 리마인더는 데스크톱 희소 → 차별화).
- **P1 — 폴더 동기 지원(로컬-퍼스트 유지)**: 저장 폴더 위치 지정 + 외부 변경 자동 리로드.
  계정/서버 없이 OneDrive/Syncthing 편입 (Joplin 파일시스템 동기 선례).
  저장소에 `__version` + rename 점유 재시도 보강.
- **P1 — 템플릿/스니펫, 인덱스 표시 토글, 다크모드**.
- **P2 — 자동 리셋 체크리스트(반복 할일), LAN QR 읽기 전용 모바일 뷰, 색/상태 라벨,
  클립보드 히스토리 연동, 휴지통, 전체화면 자동 숨김**.
- **제외/보류**: 계정·서버·실시간 협업(로컬-퍼스트 원칙), WebDAV 직접 동기(P3 이후),
  슬롯별 손잡이 위치(의도한 단순화 유지).

**기술 결정**:

- 저장은 JSON 파일 + 원자적 교체 유지. rename 점유 실패 재시도 추가.
  SQLite는 실익 없어 보류. 외부 변경 자동 리로드는 migrate() 경유로 정규화.
- 에디터는 contentEditable 유지 (리치텍스트 전제) — IME 원칙(조합 중 DOM/속성 변경 금지) 준수.
- 품질 게이트: `npm run build` → `cargo fmt --check` → `clippy -D warnings` → `cargo test`
  → debug exe `--selftest` (vite 선행) + CDP 스크립트.
- tauri `rust-version` 표기 갱신(2.12.x는 Rust ≥1.90).
- `noRedirectionBitmap`(tauri ≥2.12)로 흰 플래시/DWM 경합 완료 검토.
- `Updater allowDowngrades`(≥2.12 플러그인 설정)로 롤백 경로 확보 검토.
