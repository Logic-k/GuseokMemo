# q01 — 구석메모 경쟁/대안 조사: Windows 데스크탑 메모·스티키 노트·화면 가장자리 앱

- 조사일: 2026-11-18
- 질문: Peekom, Stickies(Zhorn), Simple Sticky Notes, Notezilla, Microsoft Sticky Notes 및 GitHub 오픈소스 sticky/edge-memo 프로젝트의 인기도·활동·라이선스·기능·차별점 조사
- 비교 기준: 구석메모 v0.2.4 (Tauri 2 + Vanilla JS/WebView2, 로컬 전용, 인덱스 10개, 빼꼼/얼음, 리치텍스트+자동 마크다운, 이미지 5장, 체크리스트, JSON 백업, txt/md 내보내기, 전역 단축키, GitHub Releases 자동 업데이트)

---

## 1. 한눈에 보는 요약

- **같은 "화면 가장자리" UX**를 노리는 프로젝트가 2025~2026년에 다수 등장했다. Windows용으로는 **StickyEdges(Electron, MIT)**, **Quick-Note-Panel(Electron, MIT)**, **0atxl/stickies(Rust+GTK4, MPL-2.0)**, **BetterStickies의 side notes(프로프라이어터리)** 가 직접 경쟁권이고, macOS에는 **noty(517★, MIT)**, Slidenote가 있다. 모두 별 수가 작아 구석메모가 Windows 쪽에서는 사실상 선두권이다.
- **스티키 노트 대중 프로젝트**로는 **PaperTodo(WPF, 2.8k★)** 가 압도적이며, "캡슐 접힘 → 화면 가장자리 자동 정렬" 기능으로 edge UX와도 맞닿아 있다.
- **상용/프리웨어**는 모두 "데스크톱에 노란 쪽지" 방식이라 edge 인덱스 방식은 Peekom이 유일하다. 대신 검색·리마인더·창 연동·동기화 등 구석메모에 없는 기능을 오래 전부터 제공한다.

## 5. 구석메모가 배울 점 (우선순위 제안)

1. **전체 메모 검색 + 메모 목록/관리 창** — 거의 모든 경쟁자의 공통 기능. Simple Sticky Notes의 Note Explorer(검색+노트북+휴지통), BetterStickies의 검색 브라우저(카드+라이브 미리보기)가 모범 사례. 인덱스가 10개뿐이라 지금은 수요가 작지만, 향후 "인덱스 확장"이나 "아카이브"를 넣는 순간 필수가 된다. 검색을 넣으면 휴지통(삭제 복구)도 같이 설계하는 게 자연스럽다.
2. **리마인더/알람** — Stickies(지정 시각·반복 sleep), GloboNote(스누즈), Slidenote(항목별 날짜→OS 캘린더 위임). 로컬 전용 철학과 충돌하지 않으며, 체크리스트 항목 단위 리마인더(Slidenote 방식)는 구석메모의 체크리스트와 궁합이 좋다.
3. **클릭 가능한 링크 + 링크 붙여넣기 시 제목 페치** — GloboNote의 URL 감지, Slidenote의 "링크 붙이면 페이지 제목", Notezilla의 마크다운 링크. 구현 비용 대비 체감이 큰 기능.
4. **창/문서 연동(attach)의 경량 버전** — Stickies·Notezilla·신형 MS Sticky Notes 공통의 차별 기능. 전체 구현은 무겁지만 "메모가 열렸던 창을 기억" 수준(MS의 소스 캡처)은 단순화 가능.
5. **전체화면 감지 시 자동 숨김** — Quick-Note-Panel의 "fullscreen protection". edge 앱은 게임/영상 전체화면 위에 탭이 뜨는 고질적 문제가 있어, edge 앱끼리는 사실상 표준 기능.
6. **파일/폴더 바로가기 붙여넣기** — BetterStickies·GloboNote. 파일을 메모에 떨구면 바로가기 아이콘. 첨부(복사)가 아니라 링크라서 로컬 저장 철학과도 충돌 없음.
7. **자동 롤링 백업** — BetterStickies(노트별 파일+7일 자동 백업), PaperTodo(백업 보존). 구석메모는 수동 JSON 백업만 있음.
8. **네이티브 .md 저장 + 외부 편집 동기화** — Quick-Note-Panel. 저장 포맷을 평문 파일로 두면 Obsidian/VSCode 생태계와 연결되고 데이터 이식성이 극대화됨. 구석메모의 JSON 단일 저장과 트레이드오프 검토 가치 있음.
9. **클릭 투과(click-through) 잠금** — imlinhanchao/sticky_notes. "얼음" 모드의 한 단계 위: 보이지만 클릭은 뚫고 지나가는 읽기 전용 고정.
10. **UI/UX 디테일** — noty의 부채질 탭 펼침과 메모 본문 암호화, PaperTodo의 "관리 기능을 의도적으로 배제"하는 철학(기능 팽창 억제의 근거로 인용 가능), StickyEdges의 호버-살짝-펼침 인터랙션.
11. **텍스트 도구 우클릭 메뉴** — PinnyNotes의 정렬/JSON prettify/날짜 삽입 등. 메모를 간이 유틸리티로 만드는 방향.
12. **시장 위치 메모** — Windows edge-memo OSS는 모두 별 수가 한 자릿수~10 수준으로 아직 초기이고, 별 수가 큰 PaperTodo(2.8k)는 "edge 접힘"을 부가 기능으로만 둔다. **"Windows + 화면 가장자리 인덱스 + 로컬 전용" 조합에서 구석메모의 직접 경쟁자는 사실상 Peekom(유료)뿐**이며, 오픈소스·완전 무료라는 포지셔닝이 그대로 차별점이다.

## 7. 메모

- Peekom 사이트(peekom.com)는 JS 렌더링이 필요해 기능 상세/가격 숫자를 fetch로 확인하지 못했다. Free/Plus 구조와 단축키 표만 확보. Plus 정가는 미확인 — 필요하면 브라우저로 직접 확인 권장.
- GitHub stars는 fetch 시점(2026-11-18) 기준이며 소수 단위 변동 있음.
- BetterStickies는 저장소에 소스가 없고(README+이미지+릴리스 안내만) "proprietary software disclaimer"가 커밋 로그에 있어 오픈소스가 아닌 무료+유료(Premium) 모델로 분류했다.
- GloboNote의 라이선스는 SourceForge에 GPLv2로 표기되나 사용자 리뷰에 "소스 비공개 프리웨어" 지적이 있어 정확한 현재 상태는 불명확(확신도 낮음, 표에도 그대로 표기).
- 추가로 볼 만한 것(이번에 미조사): 7 Sticky Notes(중단된 프리웨어), StickyPad, iQ Notes, Stick A Note, SideSlide(가장자리 컨테이너, 메모 앱은 아니지만 UX 유사).
